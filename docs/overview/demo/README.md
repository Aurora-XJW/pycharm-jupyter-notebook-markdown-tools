# 功能演示素材

用于在本机 PyCharm 中实际操作和截图，不改动已有 Notebook。

## 文件

- `功能演示.ipynb`：四项功能的操作区，以及单独标明的预置参考素材。
- `markdown-example.svg`：由本项目矢量图形组合的示例素材，不使用外部图片或字体。
- `markdown-example.png`：使用本机 JetBrains SVGLoader 从 SVG 渲染的 960×480 PNG，供剪贴板粘贴测试。

## 操作区

1. 图片管理：把示例 PNG 复制为剪贴板位图，在第一项的空白行粘贴，设置展示宽度 600 px。
2. 文字颜色：选择“用颜色标记重点内容”，打开“文字颜色…”并设置 `#E53935`。
3. 预览空行：光标放在“空行上方”和“空行下方”之间的空白行，双击 Alt 后输入 3。
4. 可视化表格：光标放在第四项末尾空白行，双击 Alt 后选择“添加表格…”。可输入三列“项目、说明、数量”。

Notebook 仅含 Markdown 单元，不包含代码或执行输出。参考素材使用同目录相对路径。操作区初始不含插件生成的图片标签、颜色标记、空行标记或表格；这些应在实际截图时由插件现场生成。
